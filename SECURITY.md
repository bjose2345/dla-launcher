# Security policy

DLA Launcher handles untrusted archives, packages, media, filesystem paths,
deep links, and native launch requests. Security reports are welcome.

## Reporting a vulnerability

Do not open a public issue for an unpatched vulnerability. Use GitHub's private
vulnerability reporting for this repository:

https://github.com/bjose2345/dla-launcher/security/advisories/new

Include the affected version and platform, impact, reproduction steps, and a
minimal synthetic sample when one is required. Never attach a real user
library, private catalog, signing key, or unreviewed diagnostic bundle.

The project is currently pre-release. Security fixes target the latest source
and the newest published release; older alpha builds may not receive backports.
